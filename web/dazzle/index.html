dazzle in the page

dazzle on GitHub scaly.io

The DSSSL engine, ported to Scaly and compiled to WebAssembly, setting pages in this browser tab: the same layout as its PDF output, drawn onto a canvas. The files below are its file system; nothing leaves the page.

Files

A binary file: kept as it was read.

The first file is the document, the second the stylesheet. Fonts (.ttf) and images go in with “Open files…”: a font is in /fonts, where dazzle looks for its font families, and the canvas draws with the same file.
